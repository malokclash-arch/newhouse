# معرض البيت الجديد — منصة إدارة المبيعات والأقساط

## محتويات المجلد
- `index.html` — الصفحة الرئيسية (افتحها بالمتصفح)
- `css/style.css` — التصميم والتوافق مع الهاتف والكمبيوتر
- `js/app.js` — البرمجة: الدخول والمستخدمون، المنتجات، البيع، الاستحصال، العملاء، الخزنة، سجل العمليات
- `manifest.json` و `icons/icon.svg` — لإضافة المنصة كتطبيق على شاشة الهاتف

## أول تشغيل
1. فك الضغط وافتح `index.html`.
2. أنشئ حساب المدير (الاسم، اسم المستخدم، كلمة المرور).
3. احفظ **رمز الاسترجاع** الذي يظهر لك؛ تحتاجه إذا نسيت كلمة مرور المدير.
4. من صفحة "المستخدمون" أضف المحاسب والموظفين وحدد صلاحية كل واحد.

## المستخدمون والصلاحيات
- المدير فقط يستطيع إنشاء الحسابات وتعديلها وإيقافها.
- صلاحيات جاهزة: بائع، محاسب، محصّل أقساط، مشرف، ويمكن تخصيص أي صلاحية يدوياً.
- كل عملية (بيع، استحصال، إضافة أو تعديل منتج، إضافة عميل، مصروف، مطالبة واتساب) تُسجَّل باسم من نفّذها في "سجل العمليات".

## مطالبة العملاء عبر واتساب
في صفحة "الاستحصال" ← تبويب "المتأخرة"، اضغط "مطالبة واتساب" لفتح رسالة رسمية جاهزة بتفاصيل القسط.
اكتب هاتف المعرض وعنوانه في الإعدادات لتظهر في نهاية الرسالة.

## حفظ البيانات
البيانات تُحفظ في متصفح الجهاز. خذ نسخة احتياطية بانتظام من: الإعدادات ← تنزيل نسخة احتياطية.

## ملاحظة أمان
تسجيل الدخول هنا يمنع دخول الموظفين لما لا يخصهم ويحدد المسؤول عن كل عملية،
لكنه يعمل داخل المتصفح بدون خادم، فلا يُعتبر حماية ضد شخص لديه خبرة تقنية ويصل لنفس الجهاز.
