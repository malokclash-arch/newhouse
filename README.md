# معرض البيت الجديد — منصة إدارة المبيعات والأقساط

## محتويات المجلد
- `index.html` — الصفحة الرئيسية (افتحها بالمتصفح)
- `css/style.css` — التصميم والألوان والتوافق مع الهاتف والكمبيوتر
- `js/app.js` — كل البرمجة: المنتجات، البيع، الأقساط، العملاء، الخزنة، الإحصائيات
- `manifest.json` و `icons/icon.svg` — لإضافة المنصة كتطبيق على شاشة الهاتف

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في متصفح Chrome أو Edge أو Safari.
3. أو ارفع المجلد كاملاً إلى أي استضافة، وافتح رابط موقعك.

## حفظ البيانات
البيانات تُحفظ في متصفح الجهاز نفسه. خذ نسخة احتياطية بانتظام من:
الإعدادات ← تنزيل نسخة احتياطية، واسترجعها على أي جهاز آخر من: الإعدادات ← استرجاع نسخة.

## تعديلات سريعة
- اسم المعرض، الهاتف، العنوان، نسبة زيادة الأقساط وعدد الأشهر: من صفحة الإعدادات داخل المنصة.
- الألوان: أول قسم في `css/style.css` (المتغيرات داخل `:root`).
- أقسام المنتجات الافتراضية: ابحث عن `ثلاجات` في `js/app.js`.
- بنود الخزنة: المتغيران `CASH_IN` و `CASH_OUT` في `js/app.js`.
